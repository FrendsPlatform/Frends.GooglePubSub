# Changelog

## [1.1.0] - 2026-10-25
### Added
- Added `Success` and `Error` properties to the result.
- Added `ThrowErrorOnFailure` and `ErrorMessageOnFailure` options. By default the Task still throws on failure; disable `ThrowErrorOnFailure` to receive the error in the result instead.

### Changed
- Task now targets .NET 8.
